# Uniwork V2 uses two-repo OpenSpecs with shared protocol

Uniwork V2 will be specified through separate OpenSpec changes in `univer-cli` and Reasonix, coordinated by a shared `uniwork-protocol-v1` draft before implementation proceeds in parallel. The Univer-side spec owns `@univer/uniwork`, protocol contracts, tooling, and Worktree operations, while the Reasonix-side spec owns workspace activities, Uniwork Shell, host adapter, transcript blocks, approvals, and removal of the V1 Live Univer Preview path.

**Status**: accepted
