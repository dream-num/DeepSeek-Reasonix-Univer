# Cowork Surface is not the Cowork shell

`@univer/cowork` will provide an embedded Univer-aware work surface, not the full Cowork Mode product shell. Reasonix Desktop owns the surrounding Cowork shell, including layout, workspace focus, agent transcript, process status, commands, and recovery UI, while the Cowork Surface owns the Univer document or workbook experience that depends on Univer frontend/runtime behavior.
