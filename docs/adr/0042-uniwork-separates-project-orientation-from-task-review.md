# Uniwork separates project orientation from task review

Uniwork Shell separates project-level orientation from selected-task review so users manage work as tasks, not as agent processes. The Uniwork Project Bar is limited to project and target orientation, the Uniwork Project Tree presents sessions as tasks with task lifecycle state, the Uniwork Task Review Rail appears only for reviewable selected-task state, and the transcript records task audit events. Agent runs remain execution details under a task rather than primary navigation objects.
