# Cowork V2 uses two-repo OpenSpecs with shared protocol

Cowork V2 will be specified through separate OpenSpec changes in `univer-cli` and Reasonix, coordinated by a shared `cowork-protocol-v1` draft before implementation proceeds in parallel. The Univer-side spec owns `@univer/cowork`, protocol contracts, tooling, and Worktree operations, while the Reasonix-side spec owns workspace activities, Cowork Shell, host adapter, transcript blocks, approvals, and removal of the V1 Live Univer Preview path.

**Status**: accepted
