# Cowork Mode owns native orchestration, not Univer semantics

Reasonix Desktop will treat Cowork Mode as a native desktop workflow for Univerfile work: it owns process lifecycle, user-visible state, layout, commands, and the interpretation of agent activity around Univer tooling. Univer tooling remains the authority for Univerfile semantics, collaboration behavior, SaC, sync, Trunk, and Worktree rules, so native Reasonix UI can become deeper without turning Reasonix into a second Univer runtime.

**Status**: accepted
