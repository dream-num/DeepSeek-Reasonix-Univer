# Uniwork Surface is not the Uniwork shell

`@univer/uniwork` will provide an embedded Univer-aware work surface, not the full Uniwork Mode product shell. Reasonix Desktop owns the surrounding Uniwork shell, including layout, workspace focus, agent transcript, process status, commands, and recovery UI, while the Uniwork Surface owns the Univer document or workbook experience that depends on Univer frontend/runtime behavior.
