# Cowork is a workspace activity with its own shell

Reasonix Desktop will expose Cowork as a workspace activity alongside the existing Code activity, not as a global desktop layout style and not as a per-new-session prompt. Selecting Cowork switches the workspace into a dedicated Cowork Shell and makes new sessions default to Cowork Sessions, while existing sessions keep their persisted kind so recents and tabs restore the correct product layout.
