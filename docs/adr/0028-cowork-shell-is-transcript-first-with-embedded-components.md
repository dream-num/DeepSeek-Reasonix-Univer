# Cowork shell is transcript-first with embedded components

Cowork Shell will remain centered on the Reasonix agent conversation rather than becoming a traditional document-editor layout. `@univer/cowork` should provide a component set, such as focused surfaces, target cards, worktree cards, preview blocks, and command-result blocks, so Univer-aware UI can be embedded into the transcript, sidebar, panels, and focused work areas while Reasonix keeps ownership of session and message lifecycle. Functional pieces should also be available as headless primitives where hosts need to own the final UI.

**Status**: accepted
