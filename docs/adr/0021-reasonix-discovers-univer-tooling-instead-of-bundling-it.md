# Reasonix discovers Univer tooling instead of bundling it

Reasonix Desktop V2 will not bundle the `univer` executable by default. It will discover and configure external Univer tooling, report version and Uniwork Protocol compatibility through typed state, and support explicit local-path overrides for development, keeping Univer release cadence, native dependencies, license concerns, and binary size out of the Reasonix desktop release.

**Status**: accepted
