# Uniwork supersedes Code Activity Univer preview

After Uniwork Mode ships, Reasonix Desktop will remove the Code Activity Live Univer Preview path instead of keeping it as a lightweight `.univer` preview. Code Activity may offer Uniwork Entries for Univerfiles, but documents, spreadsheets, and slides should be handled in Uniwork as their primary workbench rather than inside the coding-agent file preview.

**Status**: accepted
