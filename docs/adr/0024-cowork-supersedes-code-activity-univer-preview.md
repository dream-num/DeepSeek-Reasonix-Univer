# Cowork supersedes Code Activity Univer preview

After Cowork Mode ships, Reasonix Desktop will remove the Code Activity Live Univer Preview path instead of keeping it as a lightweight `.univer` preview. Code Activity may offer Cowork Entries for Univerfiles, but documents, spreadsheets, and slides should be handled in Cowork as their primary workbench rather than inside the coding-agent file preview.

**Status**: accepted
